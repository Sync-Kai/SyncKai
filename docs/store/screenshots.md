# Store images

Generated by `npm run screenshots` (`scripts/screenshots/`): the **real** popup, side panel, Crunchyroll import page and in-page bubble (`src/`) are rendered by Puppeteer with a mocked `chrome` API (`mock-chrome.ts`: storage, `storage.session`, `tabs.connect` ports, `sidePanel`) and fictional demo data (`demo-data.ts`, `demo-panel.ts`: no real account, token or protected cover art). Every PNG is RGB 24-bit, no alpha, checked by `capture.ts`.

```bash
npm run screenshots                         # 5 shots × fr/en/de + marquee tile (removes stale shots)
npm run screenshots -- --locale de --shot 4 # a single shot
npm run screenshots -- --shot marquee       # the marquee tile only
```

- The popup footer shows the version read from `manifest.json`: regenerate after a version bump.
- The Schedule shot (3) is built around the generation day (today highlighted, past episodes ticked): the week shown changes with the date, which is expected.
- Captions: `scripts/screenshots/captions.ts` (`*word*` = Kai gradient highlight). Layout: `banner.ts` / `banner.css`.
- Visual identity: dark indigo gradient, SyncKai lockup top left, caption on the left, UI on the right (popup at 1.2× under a minimal browser toolbar, side panel or import page in a minimal browser window, or a mock player for the in-page bubble).
- Frames: `popup.html` (popup), `sidepanel.html` (`?tab=nowPlaying|agenda`, `&reveal=relations` scrolls to the first sequel), `import-cr.html` (import preview), `player.html` (`?kind=sync|rate|watch`).
