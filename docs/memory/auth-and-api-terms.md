- **AniList API terms of use** (read 2026-11-06 from the source of https://docs.anilist.co/guide/terms-of-use, `AniList/docs` › `docs/guide/terms-of-use.md` on GitHub; the docs site and anilist.co answer 403 to automated fetches). Check every feature against them before designing it:
  1. free for non-commercial use; above $150 of revenue per month a commercial licence is needed (contact@anilist.co). SyncKai is free, no ads;
  2. never use the API as a backup or data storage service (SyncKai's backup holds its own settings and mappings, never AniList data);
  3. no hoarding or mass collection of API data (keep short caches, the request budget and batching; no bulk catalogue crawl, e.g. a « season catalogue » or recommendation feature must fetch what it shows, cached briefly);
  4. naming: « AniList » / « AniChart » alone is forbidden as an app name; if used in a name, append « UNOFFICIAL » or « for AniList ». The extension is « SyncKai »: never rename it or a store title with AniList in it without that suffix;

SyncKai complements AniList (it writes progress to it).
