# Store images

Generated by `npm run screenshots` (`scripts/screenshots/`): the **real** popup and in-page bubble (`src/`) are rendered by Puppeteer with a mocked `chrome` API (`mock-chrome.ts`) and fictional demo data (`demo-data.ts`: no real account, token or protected cover art). Every PNG is RGB 24-bit, no alpha, checked by `capture.ts`.

```bash
npm run screenshots                         # 5 shots × fr/en/de + marquee tile (removes stale shots)
npm run screenshots -- --locale de --shot 4 # a single shot
npm run screenshots -- --shot marquee       # the marquee tile only
```

- The popup footer shows the version read from `manifest.json`: regenerate after a version bump.
- Captions: `scripts/screenshots/captions.ts` (`*word*` = Kai gradient highlight). Layout: `banner.ts` / `banner.css`.
- Visual identity: dark indigo gradient, SyncKai lockup top left, caption on the left, UI on the right (popup at 1.2× under a minimal browser toolbar, or a mock player for the in-page bubble).
