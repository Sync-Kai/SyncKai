# Platforms

Crunchyroll, Netflix, Disney+, Prime Video, series pages, player detection, updates with open tabs. Part of the project memory (`CLAUDE.md` › Project memory).

- **Crunchyroll numbering**: the JSON-LD `episodeNumber` is relative to the Crunchyroll season (One Piece E1180 → `25`). Never send it as-is as progress. Go through the season → AniList entry mapping (`seasonEpisodeNumber`, `displayedEpisodeNumber`). SPA autoplay: the URL changes BEFORE the `<h1>` and the anonymous JSON-LD node render, both still the previous episode's and agreeing: a label already owned by another episodeId is refused for `LABEL_SETTLE_MS` (2 s) after that episodeId's first read (`parsing.ts` › `LabelGuard.isUnsettled`, clock started by any guard call), so `extractEpisodeInfo` returns null (watch-session's `waitFor` and the panel's `PAGE_MEDIA_RETRY_DELAYS_MS` re-reads, 2.5 s in all, pick the rendered page); past it the same label is accepted (another audio version, same label, is durable). Keep `LABEL_SETTLE_MS` below the panel's retry total, or a refresh can end on `no-page`. The guard keeps at most `MAX_LABELS` (200) labels per page, like `watch-session.ts` › `ignoredSeries` (2-R10). A cached mapping with `numbering: 'season'` applies only when the page gives `seasonEpisodeNumber` (`shared/episode-position.ts` › `seasonPosition`, shared with the import's `numbersKnown`; decision 8, audit M6): without it (JSON-LD without `episodeNumber`, DOM fallback), the displayed number, possibly absolute, is never used in its place; the mapping is kept untouched and the episode re-resolved without caching (corpus `cr-kaiju-s3e23-no-season-position`: before, E23 was written to an airing 11-episode entry).

Safety net `singleEntryDoubt`: a single sequel entry that doesn't cover every Netflix season (or counts unknown) is « À vérifier », never cached.   - series pages (decision of 2026-10-10 reversed on 2026-10-11): `/title/{showId}` and the details window `?jbv={showId}` on any page (`parseNetflixSeriesId`; SPA query change, covered by `url-watcher.ts`; a `/watch` page wins over `jbv`, `jbv` wins over `/title`). Same metadata request with the showId (`bridge-client.ts` › `loadShow` / `peekShow`, accepted only if `showId` matches; shared cache and in-flight). Season: the only one, else the details window's season menu (label equal to the season title, else its digits matched to `seq`; read correctly on Ranma1/2 on 2026-10-11), else none (series-level, as on Crunchyroll). `seasonNumber = seq`: same keys as playback;
  - without the permission, the service worker rejects Netflix `EPISODE_COMPLETED` and `RESOLVE_PAGE_MEDIA` (scripts still active in open tabs); never read `preferredPlayer` directly: go through `effectivePlayer` / `effectivePreferredPlayer` (fallback if Netflix is removed);
