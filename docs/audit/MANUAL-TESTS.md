# Manual tests (2.2.0 and later)

**Automated coverage.** `npm run test:ext` (`scripts/ext-e2e/`, about 3 minutes, Chrome only) loads the built extension in a real Chromium against stateful fakes of AniList and MyAnimeList and fake Crunchyroll / ADN pages: accounts and token encryption, updates, sync and retries, playback detection with a real `<video>`, the side panel and its schedule, the Crunchyroll and ADN imports, backup, links to the entry, removal from the list and comments (32 scenarios, one known bug kept as an expected failure). What stays manual: anything that needs the real sites or services (real Crunchyroll / ADN / Netflix / Disney+ pages and players, real lists, real OAuth sign-in and *Reconnect*), Netflix and Disney+ (their optional host access needs the browser's native permission dialog), Firefox, the real side panel container and the global shortcuts (Alt+Shift+K, Alt+Shift+1), the Chrome Web Store update path, notifications after 12 h, screen readers, and visual checks.

What the automated tests don't cover (items marked *automated* run in `npm run test:ext`, see [BUILD.md](../../BUILD.md)): run through in **Brave/Chrome** and **Firefox**, with the `dist/` build (`npm run build`, or `npm run dev`), extension reloaded, then tabs reopened. Tick items as you go; on failure, note the browser and attach the console (F12) of the page and of the service worker.

Tip to simulate a service outage: developer tools of the popup (right-click › Inspect) or of the service worker (`chrome://extensions` › SyncKai › "service worker") › **Network** tab › right-click a request › **Block request URL** (`api.myanimelist.net` or `graphql.anilist.co`). Unblock afterwards.

## 1. Update and accounts

- [ ] **Update from the Store version** (the most important one): install the published version, sign in to AniList and MAL, leave a Crunchyroll tab open, then load the new build (*Reload*). Expected: both accounts stay connected, the open tab keeps working without reloading it (Chrome), or shows *Reload the page* as soon as playback starts (Firefox). — automated (accounts kept and data kept across an update from 2.3.0, Chrome only; the open tab and the Store version are not): `scripts/ext-e2e/accounts.ext.ts`
- [ ] **Encrypted tokens**: service worker console → `chrome.storage.local.get(['anilistToken','malToken'], console.log)`. Expected: `{ v: 1, iv, data, expiresAt }`, never the plain-text token. — automated: `scripts/ext-e2e/accounts.ext.ts`
- [ ] **Expired session**: revoke SyncKai on anilist.co (Settings › Apps), start a sync. Expected: *Session expired* in red with *Reconnect* (not *Not connected*); *Reconnect* restores everything. — automated, except *Reconnect* (OAuth): `scripts/ext-e2e/accounts.ext.ts`
- [ ] **Account switch**: block AniList, finish an episode (it goes to *Pending syncs*), disconnect AniList, sign in with another account, unblock. Expected: nothing is written to the new account. — automated: `scripts/ext-e2e/accounts.ext.ts`

## 2. Sync and controls

- [ ] **Partial failure, then Retry**: block MAL, press *+1* on a series. Expected: banner *Ep. N watched · failed on MyAnimeList* with *Retry*; unblock, click: MAL catches up, AniList doesn't change. — automated (popup): `scripts/ext-e2e/sync.ext.ts`
- [ ] **Simultaneous +1**: *+1* on the same series in the side panel and in the popup, within the same second. Expected: +2 in total on AniList and MAL. — automated (two extension pages, messages): `scripts/ext-e2e/sync.ext.ts`
- [ ] **Rewatch** (if a series lends itself to it): series being rewatched at 11/12, *+1*. Expected: *Completed* with one more rewatch; MAL is no longer in *Re-watching*. — automated: `scripts/ext-e2e/sync.ext.ts`
- [ ] **Correct**: Activity › *Recent syncs* › *Correct* on a series, then start the next episode without confirming. Expected: the card stays, nothing is written (after the batch 5 fix: the episode is remembered and applied after the decision).
- [ ] **No duplicate rating**: finish the last episode of an already rated series. Expected: no *Rate* bubble. — automated (sync result and storage, not the bubble itself): `scripts/ext-e2e/sync.ext.ts`
- [ ] **AniList ↔ MAL differences**: *Analyze*, press *+1* on a series with a difference, come back. Expected: *Changed since the analysis*, *Keep* buttons greyed out; an unchanged difference is matched normally.

## 3. Playback detection

- [ ] **Autoplay** on Crunchyroll (and Netflix): let the next episode start on its own. Expected: both episodes sync, the popup shows the right number. — automated (Crunchyroll SPA autoplay: both writes, no duplicate, recent sync on the last episode; Netflix and the popup display are not): `scripts/ext-e2e/playback.ext.ts`
- [ ] **Background tab**: open an episode in a background tab, wait more than a minute, then watch it. Expected: normal sync at the end. — automated (player created when the tab is shown, after the 30 s player timeout; Chrome's intensive throttling of tabs hidden for 5 minutes is not reproduced): `scripts/ext-e2e/playback.ext.ts`
- [ ] **Alt+Shift+K shortcut**: on a series page → *No episode playing*; on an already synced episode → *Episode already synced*; sync paused → explanatory message. — automated (the command's `FORCE_COMPLETE` message sent to the tab; the key press itself cannot be simulated): `scripts/ext-e2e/playback.ext.ts`
- [ ] **Page language**: Crunchyroll in a different language than SyncKai; page console → `document.documentElement.lang`. Expected: the site's language, not SyncKai's. — automated (fr page with SyncKai in English, en page with SyncKai in French, after the toast): `scripts/ext-e2e/playback.ext.ts`
- [ ] **ADN**: an ADN episode is detected and synced; the entry shows in the popup and the side panel. — automated (detection, writes, recent sync, toast; not the popup and side panel display): `scripts/ext-e2e/playback.ext.ts`

## 4. Netflix

- [ ] **Access removed**: Netflix turned on, Netflix tab open; remove the access in `brave://extensions` (Firefox: `about:addons` › Permissions) without reloading the tab, finish the episode. Expected: nothing is synced, popup/side panel show *Netflix is turned off*; the preferred player switches back to Crunchyroll.
- [ ] **Non-anime series**: nothing is shown, no error in Settings › Help. — not automatable: granting the optional Netflix access needs the browser's native permission dialog, which automation cannot accept.

## 5. Side panel and schedule

- [ ] **Panel while loading**: open the side panel while an episode is loading. Expected: the entry shows (no endless skeleton). — automated (panel page opened in a tab of the same window, following the active tab; page response delayed 2 s and JSON-LD rendered 1.5 s after load; the real side panel container is not): `scripts/ext-e2e/panel.ext.ts`
- [ ] **Action, then episode change**: *+1* in the side panel, then immediately start another episode. Expected: the new episode's entry stays displayed. — automated (SPA navigation rendered with its URL; with the DOM rendered after the URL the entry keeps the previous episode's number, kept as a known bug with `it.fails`): `scripts/ext-e2e/panel.ext.ts`
- [ ] **Schedule error**: block AniList, open the Schedule. Expected: the error message and *Retry* stay visible. — automated (500 on the schedule query, then *Retry* once AniList is back): `scripts/ext-e2e/panel.ext.ts`
- [ ] **Alt+Shift+1 shortcut** (Alt+Shift+& on AZERTY; if *Settings › Shortcuts* shows it as *Not set*, set it first): on a Crunchyroll or ADN episode → the panel opens, even right after the page loads, and a second press closes it (also after leaving the panel open for more than a minute: service worker asleep); with two windows each showing a panel, only the focused window's panel closes; on another site → nothing (Brave/Chrome); Firefox → the sidebar shows, a second press hides it.
- [ ] **Settings › Shortcuts** (popup and side panel): the home row shows both keys (French: *Alt+Maj+K · Alt+Maj+1 (touche &)*; English and German without the AZERTY hint); the page shows each key or *Not set*; *Change* / *Set* opens `chrome://extensions/shortcuts` (Brave: `brave://extensions/shortcuts`) or Firefox's *Manage Extension Shortcuts*. Change a key there, come back to the side panel (still open): the new key shows without reopening it. *Playback & sync* shows no key any more, only the *Keyboard shortcuts* link.
- [ ] **Default keys** (Chrome, Brave, Firefox): on a fresh install (new profile), Alt+Shift+K marks the episode as watched and Alt+Shift+1 (AZERTY: Alt+Shift+&) toggles the panel, without opening any browser menu (Firefox in French, English and German; Firefox with the new profile manager on, whose *Profiles* menu took Alt+Shift+P) and without creating a tab group (Chrome). Update an existing install: a key changed by hand is kept; note whether an untouched Alt+Shift+S / Alt+Shift+P switched to the new keys or stayed (expected from the browsers' source: switches when the new key is free).
- [ ] **Season choice**: on an episode of a series with split seasons, pick another season in the side panel, finish the episode. Expected: the progress goes to the chosen season; Settings › My data lists the match. — automated (Frieren S1/S2 from the resolver fixtures, real playback to the credits): `scripts/ext-e2e/panel.ext.ts`

## 6. Alerts, import, backup

- [ ] **Alerts without the popup**: leave the popup closed for more than 12 h with a series in progress that airs. Expected: the notification arrives.
- [ ] **Crunchyroll import**: Settings › My data › Import a watch history › Crunchyroll; turn Wi-Fi off for 5 s during "Checking episode numbering". Expected: reading resumes and completes. Reload the extension while applying: it resumes on its own. — automated (fake Crunchyroll history API in the tab; network cut on the first season lookup for two attempts; browser relaunched on the same profile during the apply instead of an extension reload; Chrome only): `scripts/ext-e2e/import.ext.ts`
- [ ] **ADN import** (Brave and Firefox, signed in on ADN): *Settings › My data › Import a watch history › ADN* (or the *ADN* switch on the import page). Expected: "ADN tab ready", *Read my history* shows the pages read, then the analysis and the preview; series labelled "ADN: …"; an episode only started (a few seconds) never raises the progress; a donghua / manhwa (e.g. *The Girl Downstairs*) is either matched with certainty or listed in *To check*, never written blindly. ⚠️ *Update N series* writes to the real AniList / MyAnimeList lists: check the preview first, uncheck what you don't want, or stop at the preview and *Start over*. — automated (preview with "ADN: …" rows, started episode not counted; the donghua / manhwa case and Firefox are not): `scripts/ext-e2e/import.ext.ts`
- [ ] **ADN import, signed out**: sign out of ADN (or wait for an expired session), read again. Expected: "Open ADN in that tab and sign in (reload the page if you already are)", no analysis. Sign in, reload the ADN tab, read again: it works. — automated: `scripts/ext-e2e/import.ext.ts`
- [ ] **ADN import, privacy**: DevTools of the ADN tab › Network: one `viewing/history?offset=…&limit=100&onlyNext=false` request per 100 episodes, no cookies sent, the same headers as the site; Console: no token printed. DevTools of the import page: the port messages carry episodes only. — automated (2 requests for 150 episodes, the site's headers, no cookie sent while the site has one, token absent from `chrome.storage` and from every console; the port payload itself is not checked): `scripts/ext-e2e/import.ext.ts`
- [ ] **Netflix import, access not granted** (Brave and Firefox, Netflix turned off in *Settings › Playback & sync*): *Settings › My data › Import a watch history › Netflix*. Expected: the page explains that Netflix is optional and *Allow access* asks for netflix.com; once granted, *Settings › Playback & sync* shows Netflix on, and an already open Netflix tab is tracked without reloading (Firefox: reload it if not).
- [ ] **Netflix import** (Brave and Firefox, signed in, profile chosen): open *Account › Viewing activity* (`netflix.com/viewingactivity`) or use *Open Netflix* on the import page, then *Read my history*. Expected: the Netflix tab's *Show more* button is clicked about once per second until it disappears (watch the tab: nothing else is clicked, no row is hidden), "Loading your Netflix history: N rows…", then "Looking for anime on AniList: x / y titles", then "Reading your Netflix progress: x / y series", then the analysis and the preview ("Netflix: …", *N titles skipped (not anime)*). Ranma ½ S1 shows progress 5 (E6 stopped before the end is not counted); One Piece Elbaph Arc E1162 (5 s) and E1180 (partial) never raise the progress; films and western series are never listed. ⚠️ *Update N series* writes to the real AniList / MyAnimeList lists: check the preview first, uncheck what you don't want, or stop at the preview and *Start over*.
- [ ] **Netflix import, stop and errors**: *Stop* while rows load → back to the start, no AniList request. Netflix tab on another page (e.g. `/browse`) → "Open netflix.com/viewingactivity in that tab"; signed out or profile gate → sign-in message. Tab opened before an extension update (old bridge) → "The Netflix tab doesn't respond: reload it", after ~20 s at most.
- [ ] **Netflix import, privacy**: DevTools of the Netflix tab › Network: only Netflix's own requests after each *Show more* click (`pathEvaluator`), then one `metadata?movieid=…&languages=en-US` per anime kept (never per non-anime title); Console: no title printed. DevTools of the service worker: `Filtre Netflix : k / 10 titres gardés` lines with counts only.
- [ ] **Backup**: *Export* from the popup (opens the *Backup* page, file name in the interface language), then import it again. Expected: settings and matches are kept. — automated (French file name, imported into a fresh profile with *Also import settings*; matches come back marked unverified, by design): `scripts/ext-e2e/import.ext.ts`

## 9. Remove from list and comment

**These checks write to your real AniList and MyAnimeList lists.** Use a throwaway anime that is in both lists (add it first with *On this page* › *Add to Plan to watch*, or on the sites), never a series you track. The automated versions run against the fakes only.

- [ ] **Remove from the popup**: *Watching* › ⋯ on the throwaway series › *Remove from list*. Expected: inline *Remove from your list?* with focus on *Cancel*; *Cancel* (or Escape) sends nothing. *Remove*: the row disappears, banner *{title}: removed from your list*; anilist.co and myanimelist.net no longer list it. Reopen the popup within 90 s: it doesn't come back. — automated: `scripts/ext-e2e/lists.ext.ts`
- [ ] **Remove from the side panel**: on a playback page of the throwaway series, *Your progress* › ⋯ › *Remove from list* › *Remove*. Expected: the card switches to *Add to Plan to watch / Watching*, no ⋯ button, *Comment* disabled with *Add the series to your list to comment on it.* — automated: `scripts/ext-e2e/lists.ext.ts`
- [ ] **Only on one service**: remove the series on myanimelist.net only, then *Remove from list* in SyncKai. Expected: removed from AniList, MAL skipped (no error). — automated (series absent from the MAL fake from the start): `scripts/ext-e2e/lists.ext.ts`
- [ ] **Failure**: block `api.myanimelist.net`, *Remove from list*. Expected: banner *… removed from your list · failed MyAnimeList* (AniList removed, MAL kept); unblock and remove again: MAL is removed. — automated (MAL `DELETE` answering 500; the second removal from the popup's MAL list): `scripts/ext-e2e/lists.ext.ts`
- [ ] **Watched again later**: after removing, finish an episode of that series. Expected: the sync adds it back to both lists (same AniList entry, the match was kept). — automated (real playback to the credits after removing from the side panel): `scripts/ext-e2e/lists.ext.ts`
- [ ] **Comment in the side panel**: *Your progress* › *Comment* › type a few lines › *Save* (or Ctrl+Enter). Expected: nothing is sent while typing; *Comment saved*; the collapsed row previews the first line; anilist.co (entry › Notes) and myanimelist.net (Edit › Comments) show the text. Clear the text and save: *Comment cleared* on both sites. — automated (*Save* for the text, Ctrl+Enter for the clear): `scripts/ext-e2e/lists.ext.ts`
- [ ] **Comment in the popup**: ⋯ › *Comment…*. Expected: editor under the row, focus in the text box, existing comment loaded (AniList's when the series is on AniList, else MAL's); Escape closes without saving; the counter stops at 6000 characters. — automated (6000 reached by typing past a 5998-character text): `scripts/ext-e2e/lists.ext.ts`
- [ ] **Not in the list**: on a series in neither list, the panel's *Comment* is disabled with its explanation; in the popup (MAL-only series with AniList connected, or removed meanwhile), saving shows *Add the series to your list to comment on it.* and nothing is added. — automated: panel; popup with the series removed from both fakes while the editor is open. A series in the MAL list only (popup's MAL list, AniList connected) is commented on MAL and never added to AniList, with *Comment saved* (by design: `background/engagement.ts` › `setListNotes` writes wherever the series is): `scripts/ext-e2e/lists.ext.ts`
- [ ] **Firefox**: same remove and comment checks in the sidebar and the popup.
