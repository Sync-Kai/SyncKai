# SyncKai 2.5.0 « Ta liste » Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the popup's left navigation rail (496 × 600), remaining time per series with a total and a sort, the « En sommeil » dormant group, and AniList friends on series cards.

**Architecture:** Pure rules in `shared/` (remaining time, dormancy, friends summary) tested first; data fields added to the existing Watching fetchers (no new request); dormant actions reuse `SET_LIST_STATUS` with two optional payload fields; friends get one cached, debounced AniList request through a new `GET_ANILIST_FRIENDS` message; UI in Preact components under `ui/components/` and the popup / panel screens.

**Tech Stack:** TypeScript strict, Preact (pages only), Tailwind 4 tokens (`src/ui/theme.css`), Vitest, Puppeteer e2e (`scripts/e2e/`), real-extension tests (`scripts/ext-e2e/`).

**Spec:** `docs/superpowers/specs/2026-11-08-2.5.0-design.md` (approved 2026-11-08). Read it with this plan.

## Global Constraints

- Popup size `width: 496px; height: 600px` (`src/popup/popup.css`); rail 56 px, icons only; content column 440 px.
- No new permission or host; `docs/store/permissions.md` unchanged.
- Every new UI string: English text + note in `docs/i18n/context.json` + 20 translations per term sheet (`docs/i18n/glossary/<code>.md`), logged in `docs/i18n/review/<code>.md`; `npm run i18n:check` 0 errors.
- No arbitrary colour / pixel font size in components (`src/ui/design-tokens.test.ts`); new sizes become tokens in `src/ui/theme.css` and `docs/design/README.md`.
- Friends data: memory / `chrome.storage.session` only, 10 min, keyed by `accountFingerprint('anilist')` + media id; never `storage.local`, backups or diagnostics.
- Code comments in French, commits in English (Conventional Commits), author QuentinGeerts, no mention of Claude; never run a formatter.
- One branch per part (`feature/popup-rail`, `feature/remaining-time`, `feature/dormant-series`, `feature/anilist-friends`), rebased on `develop`, merged `--ff-only` after `npm run verify`, `CI=1 npm run test:e2e` and, for UI parts, `CI=1 npm run test:i18n-layout`.

## Review Focus

- A watching list cached by 2.4.x (no `episodeMinutes`, no `listStatus`) is shown without remaining time and with no dormant group, and never throws → test in Task 3.
- An entry ahead of the catalogue (progress > released or > total) shows no remaining time and is never dormant → test in Task 4 and Task 8.
- « Annuler » after the user changed the status elsewhere (e.g. completed on MAL in the meantime) never overwrites it → test in Task 10 (`onlyFrom`).
- Rapid season picks on a Crunchyroll series page send no friends request until the entry settles 1.5 s → test in Task 13.
- AniList token rejected while loading friends: the section hides, no retry loop → test in Task 12.
