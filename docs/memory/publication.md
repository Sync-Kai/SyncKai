- **Firefox Add-ons (AMO)**: Gecko ID `synckai@sync-kai.github.io`, listed channel, public since 2026-10-15 (2.3.1 approved, https://addons.mozilla.org/firefox/addon/synckai/; 2.4.0 approved automatically on 2026-10-18); the earlier submissions (1.9.0 to 2.2.1, some uploaded manually because `approval_notes` were too long) never went public. Now that the add-on is public, `release.yml` only sends `version` (license, review notes `approval_notes`) and the listing is edited manually (`docs/store/amo.md`); `docs/store/amo-metadata.json` stays the reference for the listing texts.
- **Store screenshots**: `npm run screenshots` → `docs/store/screenshots/{fr,en,de}/`, at 1280×800. The popup, the side panel and the import page are rendered from `src/` (Vite server) with a fake chrome API (`scripts/screenshots/demo-panel.ts` for the panel and the import page); the displayed version comes from `manifest.json`: regenerate after every version bump. Promo tiles: `docs/store/promo-440x280.png` (`npm run icons`) and `docs/store/promo-1400x560.png` (`npm run screenshots`), in English (shared by all languages).
